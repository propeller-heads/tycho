# 1. Setup

### Install Rust and mise

Install <a href="https://rustup.rs/" target="_blank" rel="noopener noreferrer">rustup</a> and <a href="https://mise.jdx.dev/getting-started.html" target="_blank" rel="noopener noreferrer">mise</a>, then <a href="https://mise.jdx.dev/getting-started.html#activate-mise" target="_blank" rel="noopener noreferrer">activate it</a> in your shell. rustup installs the Rust toolchains that the repository's `rust-toolchain.toml` files pin. mise installs the other tools, such as the Substreams CLI and Buf, at the versions in `mise.toml`.

### Fork the monorepo

1. Start by making a fork of the <a href="https://github.com/propeller-heads/tycho-indexer" target="_blank" rel="noopener noreferrer">Tycho monorepo</a> repository
2. Clone the fork you just created
3. Install the pinned tools and make sure everything compiles fine

   ```bash
   mise install
   cd protocols/substreams
   cargo check --all
   ```
