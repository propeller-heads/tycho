# Libraries: tycho's own helpers

Which tycho helper to use for a need, by layer, so a change does not re-implement what the repo
already provides. Each row gives the need, what to use (crate and path), the hand-rolled pattern it
replaces and how to spot that pattern in a diff. No table is complete: before accepting a new
helper, type or loop, search the workspace for an existing equivalent.

## Rules

### serial-db-tests
Source: `.claude/CODEBASE.md` § Testing
Spot: New DB-backed tests without serial_db in the name or with hand-rolled setup/teardown.
Applies: rust-test · look first at lines matching `db|database|postgres|serial|sql|conn|migrat|gateway`
Checked by: ast-grep `rust-serial-db-test-name`
